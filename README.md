# One-Sentence Absurd Invention Pitch

This entry pitches the Farewell Charger: a phone charger that, the moment your battery hits 1%, texts your group chat that you died bravely mid-sentence, so nobody ever expects a reply again. It fixes the tiny everyday annoyance of a dying phone not by saving the battery, but by giving you a heroic exit instead.

Run `main.py` (Python standard library only) and it writes the one-sentence pitch to `/output/entry.txt`, deterministically — the same 135-character sentence every run.
